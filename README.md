# Antimicrobial resistance in intra-abdominal infections worldwide: a systematic review and meta-analysis

## Overview

This repository accompanies the manuscript *Antimicrobial resistance in intra-abdominal infections worldwide: a systematic review and meta-analysis*. It provides study-level extracted antimicrobial resistance (AMR) data, R scripts for statistical analyses, and analytical outputs to facilitate transparency and reproducibility.

The systematic review included 104 studies from 29 countries, encompassing more than 58,000 bacterial isolates. PubMed, Web of Science, and Embase were searched for studies published between January 1, 2005 and August 27, 2025. The review protocol was registered in PROSPERO (CRD420251144048).

## Data files

| File                        | Description                                                                                                                                 |
|-----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|
| `data/E.coli.xlsx`          | *Escherichia coli*                                                                                                                          |
| `data/KP.xlsx`              | *Klebsiella* spp.                                                                                                                           |
| `data/PA.xlsx`              | *Pseudomonas aeruginosa*                                                                                                                    |
| `data/AB.xlsx`              | *Acinetobacter baumannii*                                                                                                                   |
| `data/SA.xlsx`              | *Staphylococcus aureus*                                                                                                                     |
| `data/Enterococcus.xlsx`    | *Enterococcus* spp.                                                                                                                         |
| `data/meta_regression.xlsx` | Study-level data for temporal trend analyses of third-generation cephalosporin and carbapenem resistance in *E. coli* and *Klebsiella* spp. |

The pathogen-specific workbooks contain worksheets for individual antimicrobials or resistance phenotypes. The core variables required for analysis are:

| Variable | Definition                                                                                                     |
|----------|----------------------------------------------------------------------------------------------------------------|
| `study`  | Study identifier or citation label                                                                             |
| `Events` | Number of resistant bacterial isolates                                                                         |
| `Total`  | Number of bacterial isolates tested for the corresponding antimicrobial or resistance phenotype                |
| `Year`   | Midpoint of the isolate-collection period, used in the meta-regression workbook; fractional years are retained |

Subgroup variables used by the supplied subgroup script are `AST method`, `Etiology`, `Income Level`, `Year Group`, `Region`, and `AST Guideline`. AST denotes antimicrobial susceptibility testing. Region refers to the World Health Organization (WHO) regional classification. Additional descriptive variables may be available in the workbooks.

The meta-regression workbook contains four worksheets: `3GCR-EC`, `CR-EC`, `3GCR-Klebsiella`, and `CR-Klebsiella`. 3GCR denotes third-generation cephalosporin resistance, and CR denotes carbapenem resistance.

Resistance proportions are based on tested bacterial isolates, not the number of unique patients or infection episodes. Missing counts should not be interpreted as zero resistance events. Worksheets lacking required analysis columns are not eligible for the corresponding analysis.

## Statistical analysis scripts

| Script                     | Purpose                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `code/PFT_REML.R`          | Primary random-effects meta-analysis of proportions using the Freeman–Tukey double-arcsine transformation (PFT) and restricted maximum likelihood (REML) estimation. Pooled proportions are back-transformed using the harmonic mean of study sample sizes.                                                                                                           |
| `code/GLMM_ML.R`           | Sensitivity analysis using a binomial generalized linear mixed model (GLMM) with a logit link and maximum likelihood (ML) estimation.                                                                                                                                                                                                                                 |
| `code/Subgroup_analysis.R` | PFT–REML subgroup analyses, tests for subgroup differences, and forest plots. Individual study confidence intervals (CIs) are calculated using the exact Clopper–Pearson method. For subgroups with one study, the exported subgroup estimate is descriptive, with an exact binomial 95% CI and no between-study heterogeneity statistic or prediction interval (PI). |
| `code/Meta_Regression.R`   | Random-effects meta-regression of logit-transformed resistance proportions against the midpoint year of isolate collection using REML. A continuity correction of 0.5 per binomial cell is applied only to studies with zero or all events. Outputs include annual odds ratios, 95% CIs, P values, residual heterogeneity, pseudo-R², and bubble plots.               |

The primary, GLMM sensitivity, and subgroup scripts use a minimum tested-isolate count of 10 per study-level observation. The meta-regression script retains its Stata-comparison settings (`min_total = 1`, `min_studies = 3`); the supplied meta-regression workbook contains no otherwise eligible observations with fewer than 10 tested isolates. The scripts contain their specific data-cleaning rules and model settings. GLMM fitting warnings, errors, and unavailable intervals should be reviewed, particularly for sparse or boundary-only datasets.

## Software requirements

The target analysis environment is R 4.4.2, with `meta` 8.2.0 and `metafor` 4.8.0. Additional required packages are `readxl`, `openxlsx`, `dplyr`, and `ggplot2`.

Install the dependencies in R if they are not already available:

``` r
install.packages(c("readxl", "openxlsx", "dplyr", "ggplot2", "remotes"))
remotes::install_version("meta", version = "8.2.0", upgrade = "never")
remotes::install_version("metafor", version = "4.8.0", upgrade = "never")
```

The subgroup forest-plot script uses a version-specific modification of the internal `forest.meta` function to display exact study-level CIs while retaining the PFT back-transformation for pooled estimates. Use `meta` 8.2.0 for this script. Cairo PDF support and the Times New Roman font are also required for the intended subgroup plot rendering. Check Cairo support using `capabilities("cairo")` in R.

Stata 18 reference estimates are embedded in the meta-regression script for comparison. Stata is not required to run the supplied R scripts.

## Reproducing the analyses

Download the repository using **Code \> Download ZIP** on GitHub, or clone it using Git:

``` bash
git clone https://github.com/13773361306/resistance-meta-analysis.git
cd resistance-meta-analysis
```

If downloading the ZIP file, extract it and open a terminal in the extracted repository root (the directory containing `code/` and `data/`). Ensure that `Rscript` is available in the terminal. All commands below are run from this root directory.

### 1. Primary meta-analysis (PFT–REML)

``` bash
Rscript code/PFT_REML.R data/E.coli.xlsx
Rscript code/PFT_REML.R data/KP.xlsx
Rscript code/PFT_REML.R data/PA.xlsx
Rscript code/PFT_REML.R data/AB.xlsx
Rscript code/PFT_REML.R data/SA.xlsx
Rscript code/PFT_REML.R data/Enterococcus.xlsx
```

### 2. Sensitivity analysis (GLMM–ML)

``` bash
Rscript code/GLMM_ML.R data/E.coli.xlsx
Rscript code/GLMM_ML.R data/KP.xlsx
Rscript code/GLMM_ML.R data/PA.xlsx
Rscript code/GLMM_ML.R data/AB.xlsx
Rscript code/GLMM_ML.R data/SA.xlsx
Rscript code/GLMM_ML.R data/Enterococcus.xlsx
```

### 3. Subgroup analyses

For the principal resistance phenotypes in *E. coli* and *Klebsiella* spp.:

``` bash
Rscript code/Subgroup_analysis.R data/E.coli.xlsx
Rscript code/Subgroup_analysis.R data/KP.xlsx
```

The script processes worksheets containing the required columns and available subgroup variables. Other pathogen workbooks can be supplied in the same way when the relevant subgroup variables are present.

### 4. Temporal trend analyses (meta-regression)

``` bash
Rscript code/Meta_Regression.R data/meta_regression.xlsx
```

### Running from RStudio

Set the working directory to the repository root using **Session \> Set Working Directory \> Choose Directory**. Check the location in the R console:

``` r
getwd()
file.exists("data/E.coli.xlsx")
file.exists("data/meta_regression.xlsx")
```

Both file checks should return `TRUE`. The scripts can be run using the terminal commands above in the RStudio Terminal. Alternatively, source a script from the R console to analyze its default input workbook:

``` r
source("code/PFT_REML.R")
source("code/GLMM_ML.R")
source("code/Subgroup_analysis.R")
source("code/Meta_Regression.R")
```

The first three scripts default to `data/E.coli.xlsx`, and the meta-regression script defaults to `data/meta_regression.xlsx`.

## Analytical outputs

The scripts create output directories automatically and organize results by analysis method and input workbook. The following table lists the principal generated Excel files and PDF outputs. `<dataset>` denotes the input workbook name without its `.xlsx` extension (e.g., `E.coli` or `KP`).

| Output directory                           | Principal Excel file                            | PDF outputs           |
|--------------------------------------------|-------------------------------------------------|-----------------------|
| `results/PFT_REML/<dataset>/`              | `All_Sheets_PFT_REML_Results_with_PI.xlsx`      | Forest plots          |
| `results/GLMM_ML/<dataset>/`               | `All_Sheets_Meta_Analysis_GLMM_ML_with_PI.xlsx` | `Forest_Plots/`       |
| `results/Subgroup_analysis/<dataset>/`     | `All_Sheets_Multi_Subgroup_Analysis.xlsx`       | Subgroup forest plots |
| `results/Meta_Regression/meta_regression/` | `Meta_Regression_STATA_FINAL.xlsx`              | `Bubble_Plots/`       |

The Excel outputs contain analysis summaries and, where applicable, study-level estimates, cleaned data, exclusion audits, model diagnostics or status indicators, and methods documentation. Review these records before interpreting the estimates. Prediction intervals and other model statistics may be unavailable for some datasets. Re-running a script for the same input workbook may overwrite its previous output files.
